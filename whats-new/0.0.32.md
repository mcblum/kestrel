# Kestrel 0.0.32

## Kestrel Connect

### See your sessions from any computer.

Find your Kestrel sessions on your other computers. Conversations are end-to-end encrypted, readable only by your own devices.

[Open Connections](#/settings/connections)

![End-to-end encrypted](images/connect-devices.svg)

## Also in this release

### MCP servers

Set up a server once and every session gets it, on Claude, Codex and OpenCode.

[Open Agent setup](#/settings/agent-setup)

### Autopilot

Autopilot answers failed checks, merge conflicts and requested changes on a pull request, and can merge it when it is green.

[Open Git settings](#/settings/git)

### Pull requests that need you

See which pull requests are blocked and why, without opening each one.

[Open Pull requests](#/pull-requests)

### Code reviews

Edit a review's findings before posting it, and see who has already approved or asked for changes.

[Open Code reviews](#/code-reviews)

## More changes

### Set up a new computer

Choose what to bring over from your other computers. Passwords and keys are never copied.

[Open Set up this computer](#/settings/connections/setup)

### Notes between sessions

Sessions working together pass each other a decision or a name while they work, and each gets a clear title.

### Tag suggestions

Suggestions prefer the tags you already use, and the card lets you pick one or type your own.

### Changes pane

The file list and the diff scroll on their own, with a bar between them to resize.

### Beta versions

Choose to try the next version early, in Settings → General.

[Open General settings](#/settings/general)

### Finding What's new again

This page opens once after each update. Find it again in the Help menu, and turn it off in Settings → General.
